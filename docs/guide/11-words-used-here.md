# Words used here

Purpose: explain the words this guide uses, in plain terms.
Owner: Rafiq. Version 0.1.0 (agreed by Rafiq, 2026-11-02). Date: 2026-11-02.

| Word | What it means |
|---|---|
| **The server** | The program that does all the work behind her page. It runs out of sight, in a window that is hidden on purpose. |
| **The page** | What you see in Chrome. It shows her and talks to the server. |
| **The server log** | The file `logs\assistant_server.log`. It keeps what the server prints, so you can read it when something goes wrong. |
| **A key** | A long password that lets her use an online service. See **Add, change or remove a key**. |
| **The credential store** | The place in Windows where keys are kept safe. |
| **Wake phrase** | "Hey" and her name. It tells her you are talking to her. |
| **The model** | The AI that writes her answers. She uses three: Haiku (the quick one), Sonnet (the deeper one) and Gemini (only if you pick it). |
| **Think hard** | Say these words and that one answer goes to the deeper model. |
| **Whisper** | The program that turns your speech into words. It runs on this laptop. |
| **A node** | A tool on the screen, shown as a small logo. |
| **A group** | A set of nodes, such as Google or Claude. |
| **The stage** | The big middle part of the screen. |
| **The strip** | The bar across the top that shows the laptop's load. |
| **Narrate** | A switch. When it is on, she says one short line when you open a part. |
| **The live face** | Her mouth moving to her words. It is off for now. |
| **The older assistant** | The earlier Khadijah. It used port 8340, which Khadijah now uses, so the two cannot run together. |
| **A port** | A number that tells the laptop which program a message is for. The page address ends in the port: `localhost:8340`. |
| **Localhost** | The name for "this laptop". |
| **The log** | The same file as the server log: a copy of everything the server printed. |
